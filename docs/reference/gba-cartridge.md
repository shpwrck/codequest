# GBA cartridge visual reference

Notes gathered for drawing the CSS cartridges (no third-party imagery stored).

- **Dimensions**: ~57–60 mm wide x 35 mm tall x 6–9 mm thick (Game Pak,
  Wikipedia). At this project's 4 px/mm shell scale: ~228 x 140 px; the cart
  is ~39% of the console's 144.5 mm width.
- **Shape**: wide, short rounded rectangle. The top edge has a shallow curved
  thumb recess. One bottom corner carries a small keying notch so the cart
  only inserts one way.
- **Shell**: light gray plastic. A strip across the top front carries
  embossed "GAME BOY ADVANCE" lettering (same-color relief, no ink). Thin
  grip ridges on the left and right edges.
- **Label**: a recessed label area covers most of the face below the embossed
  strip — artwork plus the game title.
- **In the console**: inserted into a top-back slot; the cart sits nearly
  flush with the shell. (This app exaggerates it — the loaded cart peeks
  above the top edge so the state is visible from the front.)

Our stand-in branding uses "CODEQUEST ADVANCE" embossing and original pack
titles; no Nintendo marks are reproduced.
